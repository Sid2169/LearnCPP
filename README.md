# LearnCPP

Small C and C++ programs written while learning the fundamentals of both languages.

## Contents

- `HelloWorld.cpp` — strings, variables, input/output, comments, and type experiments.
- `Hello.c`, `Cli.c` — early C programs.
- `Makefile` — builds every `.cpp` file in the directory with `g++`.

## Building

```sh
make
```

This compiles each `.cpp` file into an executable with the same base name. Individual programs can also be built directly:

```sh
g++ -Wall -std=c++11 HelloWorld.cpp -o HelloWorld
```
